# Day 16 - Basic To-Do List

## Project Description

This project is a basic To-Do List web application created using HTML5, CSS3, and JavaScript.

The application allows users to add tasks and remove tasks from the list without using database storage or persistence.

## Objective

The main objective of this project is to practice:

- JavaScript arrays
- Array manipulation
- DOM manipulation
- Event handling
- Event delegation
- Dynamic list rendering
- User input handling

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Add new tasks
- Display tasks dynamically
- Delete individual tasks
- Press Enter to add a task
- Input validation
- Responsive design
- Clean and simple user interface
